# سفرة — SaaS لإدارة المطاعم

تطبيق Django عربي RTL لإدارة المنيو والطاولات وطلبات الضيوف والمطبخ والخدمة. بدأ من مواصفات [المنتج الأصلية](safra_restaurant_saas_complete_spec.md) في هذا المجلد. الواجهة تتكيف مع الهاتف والتابلت وسطح المكتب.

## ما يعمل الآن

- إنشاء حساب مالك ومطعم وتجربة 14 يومًا، وتسجيل دخول الموظفين بأدوار واستعادة كلمة المرور عبر البريد.
- إدارة الفروع واختيار الفرع الحالي، وربط الموظف بفرع مسموح وتعطيل عضويته أو تغيير دوره.
- تعديل اسم المطعم ووصفه وبيانات اتصال الفرع وساعات العمل، مع خيار لنشر بيانات الفرع في منيو الضيف.
- إدارة التصنيفات والأصناف والأسعار والصور والتوفر والإضافات، والطاولات مع تنزيل QR وتجديد الرمز.
- منيو ضيف عام بلا تسجيل، سلة مع كمية وإضافات، إرسال طلب مع إعادة احتساب الأسعار في الخادم ومفتاح منع التكرار.
- شاشة مطبخ تفحص البيانات كل 10 ثوانٍ وتوضح حالة الاتصال، انتقالات حالات مسجلة، واستدعاء الويتر أو الحساب.
- طلب تقليدي متعدد الأصناف والإضافات من الموظف، إلغاء بسبب مسجل، تحصيل يدوي منفصل عن حالة الطلب، تقارير وتصدير CSV، ولوحة مشغل لإدارة المطاعم والاشتراكات مع سبب وسجل تدقيق.

**الحالة:** إصدار تجريبي تشغيلي، وليس جاهزًا للإطلاق التجاري. تفاصيل المؤجل والمخاطر في [خطة التنفيذ](docs/IMPLEMENTATION_PLAN.md).

## التشغيل المحلي

يتطلب Python 3.12+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

افتح `http://127.0.0.1:8000/` ثم أنشئ حساب المطعم. لإنشاء مدير منصة: `python manage.py createsuperuser` ثم افتح `/platform/`. تبقى `/django-admin/` لإدارة الكيانات الداخلية مثل الباقات.

للتطوير عبر PostgreSQL: `docker compose up --build` ثم `docker compose exec web python manage.py migrate`. إعدادات التطوير داخل Compose فقط.

## الاختبارات

```powershell
python manage.py check
python manage.py test core
```

## البيئة

انسخ `.env.example` إلى إعدادات بيئتك المناسبة. Django لا يقرأ ملف `.env` تلقائيًا؛ عرّف المتغيرات في shell أو نظام النشر. `DATABASE_URL` اختياري محليًا ويجب ضبطه للإنتاج على PostgreSQL. لا تستخدم مفتاح التطوير أو `DEBUG=1` في الإنتاج.

في التطوير، رابط استعادة كلمة المرور يُطبع في مخرجات الخادم. في الإنتاج يجب إعداد SMTP باستخدام متغيرات `DJANGO_EMAIL_*` قبل الاعتماد على الاستعادة.
