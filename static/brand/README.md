# Serveza brand assets

The primary logo comes from the owner's `logo.jpeg`. The shared template `_brand_logo.html` serves an 800-pixel WebP and a full-resolution 1600-pixel WebP. Both preserve the supplied artwork, background and proportions.

The square icon, favicons and home-screen icon use the phone symbol cropped from the same artwork. The Apple touch icon also has a PNG compatibility copy. The legacy SVG favicon embeds the 192-pixel WebP.

The stacked, monochrome and reversed WebP files preserve the alternate artwork from the original brand book. Product pages use the supplied horizontal logo on light and dark surfaces.
