# خطة التنفيذ والحالة

المرجع هو ملف المواصفات الأصلي في الجذر. التطبيق قابل للتجربة، لكنه لم يحقق جميع قصص المستخدم أو شروط الإطلاق التجاري.

| المجال | الحالة | التفاصيل |
|---|---|---|
| الأساس والحسابات والعزل | جزئي | تسجيل ودخول واستعادة كلمة المرور، فروع وعضويات وأدوار وتعطيل الموظف واختبارات عزل؛ لوحة إعداد للمالك والمدير محسوبة من بيانات الفرع؛ تحرير ملف المطعم وبيانات اتصال الفرع مع نشر اختياري في منيو الضيف. تفعيل البريد والدعوات وإعداد العملة واستكمال جولة الإعداد مؤجلة. |
| الباقات | جزئي | تجربة 14 يومًا وحدود فروع وطاولات وأصناف وموظفين في خدمة مركزية، وخفض الباقة دون حذف بيانات، وتعليق المطعم بوضع قراءة فقط؛ فوترة ومدفوعات وتجربة تزامن على PostgreSQL مؤجلة. |
| المنيو والطاولات | جزئي | تصنيفات مع إظهار/إخفاء، أصناف مع تعديل وتوفر، صور وأحجام بأسعار مستقلة وإضافات وQR؛ الاستيراد وإدارة خيارات أوسع مؤجلة. |
| طلب الضيف | منفذ للمسار الأساسي | سلة، تحقق خادمي، لقطة سعر، منع تكرار، متابعة حالة. تحتاج اختبارات ضغط وتزامن إضافية. |
| شاشة المطبخ | جزئي | عرض وتحديث حالات وفحص اتصال واستعادة عبر polling كل 10 ثوانٍ؛ المحطات والصوت وWebSocket مؤجلة. |
| الخدمة والطلب التقليدي | جزئي | استدعاء الويتر والحساب وطلب موظف متعدد الأصناف والإضافات بنفس خدمة تسعير QR؛ إلغاء بسبب مسجل، وتعديل الطلب الجديد أو المستلم وغير المدفوع مع سجل نسخ قبل/بعد ومزامنة شاشة المطبخ. تعديل الطلب بعد بدء التحضير غير مسموح. |
| التقارير وإدارة المنصة | جزئي | أعداد وقيمة الطلبات والتحصيل اليدوي وأكثر الأصناف ومتوسطات التشغيل وتصدير CSV؛ لوحة مشغل للمطاعم والاشتراكات مع سبب وسجل تدقيق. تحرير الباقات داخل Django Admin يتطلب سببًا، والكيانات التشغيلية فيه للقراءة فقط. |
| صلابة الإنتاج | غير مكتمل | تحديد معدل الدخول واستعادة الحساب في قاعدة البيانات موجود؛ ما زالت مراقبة ونسخ احتياطي مجرّب واختبارات حمل ومراجعة أمنية وميدانية مطلوبة. |

## الخطوات التالية

1. اختبار تزامن حدود الباقات ومنع تكرار الطلبات على PostgreSQL تحت حمل حقيقي.
2. استكمال خيارات إدارة المنيو المتقدمة والاستيراد، ودراسة مسار الطلب الإضافي بعد بدء التحضير.
3. إضافة قنوات تحديث لحظية عند تحديد استضافة مناسبة، مع إبقاء الاستعلام الدوري للاستعادة.
4. إضافة اختبارات واجهة للهاتف والتابلت والكمبيوتر واختبارات ضغط وعزل أوسع.
5. تشغيل تجربة مطعم فعلية ثم تثبيت التسعير والحدود وبيئة النشر.
