# خطة التنفيذ والحالة

المرجع هو ملف المواصفات الأصلي في الجذر. نفّذنا جزءًا قابلًا للتجربة من المراحل 0–7، وليس جميع قصص المستخدم.

| المجال | الحالة | التفاصيل |
|---|---|---|
| الأساس والحسابات والعزل | جزئي | تسجيل ودخول وعضويات وأدوار واختبارات عزل؛ استعادة كلمة المرور ودعوات البريد مؤجلة. |
| الباقات | جزئي | تجربة 14 يومًا وحدود أولية؛ إدارة مدفوعات وخفض الباقة والتزامن القوي مؤجلة. |
| المنيو والطاولات | جزئي | تصنيفات وأصناف وصور وإضافات وQR؛ الأحجام والاستيراد وواجهة تعديل الإضافات المتقدمة مؤجلة. |
| طلب الضيف | منفذ للمسار الأساسي | سلة، تحقق خادمي، لقطة سعر، منع تكرار، متابعة حالة. تحتاج اختبارات ضغط وتزامن إضافية. |
| شاشة المطبخ | جزئي | عرض وتحديث حالات واستعادة عبر polling؛ المحطات والصوت وWebSocket مؤجلة. |
| الخدمة والطلب التقليدي | جزئي | استدعاء الويتر والحساب وطلب موظف لصنف واحد؛ تعديل الطلب القائم مؤجل. |
| التقارير وإدارة المنصة | جزئي | أعداد وتصدير CSV وDjango Admin؛ تقارير الأزمنة ولوحة SaaS مخصصة مؤجلة. |
| صلابة الإنتاج | غير مكتمل | مراقبة ونسخ احتياطي مجرّب وحماية معدل موزعة واختبارات حمل ومراجعة أمنية وميدانية مطلوبة. |

## الخطوات التالية

1. نقل منطق حدود الباقات إلى خدمة مركزية بقفل معاملات PostgreSQL واختبارات تزامن.
2. استكمال إدارة الموظفين والفروع والأحجام والإضافات وسجل التدقيق.
3. إضافة قنوات تحديث لحظية مع fallback موثق، واختبار اتصال المطبخ في ظروف الشبكة الضعيفة.
4. إضافة اختبارات واجهة للهاتف والتابلت والكمبيوتر واختبارات ضغط وعزل أوسع.
5. تشغيل تجربة مطعم فعلية ثم تثبيت التسعير والحدود وبيئة النشر.
