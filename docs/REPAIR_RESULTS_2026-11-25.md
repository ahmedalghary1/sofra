# نتائج إصلاح مشروع Serveza

نفذت الإصلاحات المحلية الواردة في [خطة 25 نوفمبر 2026](REMEDIATION_PLAN_2026-11-25.md). عولجت الملاحظات التقنية T01 إلى T19، وأضيفت وظائف وإجراءات لمعالجة فجوات التحصيل والاشتراكات والأرشفة والتقارير. لا تمثل هذه النتيجة اعتمادًا للاستضافة أو جاهزية تجارية؛ تبقى البنود الخارجية موضحة أدناه.

## ما تغير

| المجال | النتيجة |
| --- | --- |
| الصور T01 | إعادة بناء الصورة من البكسلات باسم عشوائي وامتداد PNG؛ لا ينقل HTML اللاحق أو EXIF. فحص الوسائط السابقة للقراءة فقط، وإعداد Nginx لمنع الامتدادات غير الآمنة موثق. |
| الإرسال T02 وT03 | تثبيت حمولة طلب الموظف ومفتاحه وطاولته عند غياب التأكيد واستعادتها بعد تحديث الصفحة. تكرار الطلب المحفوظ يرجع النتيجة حتى بعد الإيقاف، دون السماح بإنشاء جديد. |
| المصادقة T04 وT05 | شمول Django Admin بحد الدخول المشترك، وحدود للتسجيل والتواصل ومصدر المصادقة. الثقة بعنوان العميل خلف الوكيل اختيار صريح مع حماية ترويسة المصدر. |
| المقاعد T06 | احتساب الدعوات السارية في مسارات الإنشاء كلها، واستهلاك حجز الدعوة نفسها مرة واحدة عند قبولها. |
| المدخلات والمال T07 إلى T10 | معرفات محدودة النوع والمدى، وJSON وتواريخ مرفوضة بأخطاء مفهومة؛ Decimal موحد بدقتين وحدود مطابقة للحقول؛ سعر باقة غير سالب في النموذج والقاعدة. |
| الهوية T11 وT12 | منع تسجيل بريد حساب قديم مرة أخرى، ومنع اسم دخول جديد يتجاوز 150 حرفًا، مع الحفاظ على ربط الحساب القديم ذي اسم دخول مستقل وبريد أطول. لا دمج حسابات قديمة أو تغيير أسمائها تلقائيًا. |
| الاستيراد T13 وT14 | تطبيع رؤوس CSV، ورفض تعارض الصنف والتصنيف مع الموجود في المعاينة وقبل الاعتماد الذري. لا تحديث صامت للأسعار أو مضاعفة دفعة جديدة للمنيو نفسه. |
| التدقيق والأداء T15 وT16 | قيم قديمة وجديدة منظمة لتغييرات الأسعار والأسماء والإضافات والأحجام؛ تحميل أصناف السلة وعلاقاتها مرة واحدة. يثبت اختبار 40 سطرًا عدم تجاوز 4 استعلامات للمنيو بدل 120 في الحالة البسيطة السابقة. |
| الاتصال والإدارة T17 وT19 | فك ترميز DSN وتمرير خيارات SSL المعروفة؛ تفعيل علمي المشغل لدخول المنصة وDjango Admin معًا. |
| الهاتف T18 | التواصل مع Serveza متاح في قائمة التشغيل، مع بقاء العائم للموقع والضيف؛ زر الدعم لا يغطي إضافة الصنف. |
| التحصيل B01 وB05 | حركة مستقلة حسب وقت القبض والتصحيح وتصدير CSV. تصحيح قيد خاطئ بصلاحية وسبب ومفتاح وتحقق من الوقت المتوقع، مع حفظ المبلغ والتوقيت الأصليين. لا يرد أموالًا فعلية للضيف. |
| الاشتراك B02 وB03 | حفظ الشروط والاتفاقات بصورة مستقلة عن العرض العام؛ تجربة أولى صريحة 14 يومًا بلا تحصيل؛ تفعيل اختياري ذري مرتبط بإيصال بعد مراجعة السداد. لا تجديد مالي تلقائي. |
| الموارد والفروع B04 وB06 وB07 | أرشفة صريحة تحرر السعة وتحفظ التاريخ وتفحص الاستعادة، مع إنهاء الجلسات القديمة عند الأرشفة. يظل المدير مدير المطعم كله مع توضيح ذلك. تقرير تجميع ومقارنة لفروع المطعم نفسه دون مطعم آخر. |
| التشغيل R01 إلى R06 | إعداد CI لـSQLite وPostgreSQL والمتصفح، وأدوات نسخ واستعادة وفحص بيانات وسجلات توقيت ومعرف طلب وأداة صحة، وتحديث وثائق الحالة والكتالوج والنشر. |

## أدلة الاختبار وحفظ البيانات

- نجح `python manage.py check` وفحص اتساق الترحيلات و`git diff --check`.
- محاكاة إعدادات النشر بمفتاح مؤقت وإيقاف DEBUG تركت تحذيري HSTS الخاصين بالنطاقات الفرعية وpreload؛ يراجعان على النطاق الحقيقي، ولا يفعّلان تلقائيًا. نجح فحص أداة الصحة بعشرين طلب قراءة على خادم محلي مؤقت، وليس ذلك قياسًا لحمل الإنتاج.
- شغّل `python manage.py test core` 192 اختبارًا؛ نجح 188 وتُخطيت أربعة تتطلب أقفال PostgreSQL. لا تُحتسب الاختبارات المتخطاة دليلًا على نجاح التزامن.
- نجحت الحزم `scripts.test_restaurant_ui` و`test_login_ui` و`test_subscription_ui` و`test_audit_repairs_ui` معًا: 11 اختبارًا بالترتيب العادي، ثم 11 بالترتيب المعكوس. شمل التحقق 52 حالة عرض للشاشات المتغيرة باللغتين وعرضي 360 و1366، ومساري فقد الرد والتصحيح باللغتين بعرض 390. فُحصت صور الشاشة محليًا.
- نجحت اختبارات النسخ والاستعادة بملف PNG وSQLite، ومنع اجتياز مسارات الأرشيف ومنع الكتابة فوق مجلد استعادة قائم. أُعيد اختبار إعداد الوكيل والنسخ بعد المراجعة النهائية.
- قبل تطبيق `0026` حُفظت نسخة خاصة تحت `tmp` واستعيدت إلى مجلد منفصل. أثبتت مقارنة أعمدة الصفوف الأصلية في 35 جدولًا عدم تغيير أي منها. أضاف Django ثلاثة تعريفات نماذج و12 صلاحية؛ أما الحقول والجداول الجديدة فتحتوي البيانات الإضافية المقصودة. لقطة الشروط القديمة موسومة كإعداد وقت الترحيل، وليست إثبات عقد سابق.
- شُغّل `audit_release_data` على قاعدة التطوير بعد الترحيل؛ كانت نتائج فحوص البريد المكرر والأسعار السالبة وعلاقات المطاعم والفروع وامتدادات الوسائط غير الآمنة كلها صفرًا. هذا حصر للفحوص المحددة، وليس ضمانًا بأن كل بيانات ممكنة صحيحة.
- النسخ ونتائج الفحص والصور تحت `tmp` المستبعد من Git. لم تُضف مفاتيح أو قواعد بيانات أو وسائط إلى تغييرات المستودع.
