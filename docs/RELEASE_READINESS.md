# بوابة Docker — 28 نوفمبر 2026

أُضيف إعداد تشغيل السيرفر ودليل `DOCKER.md` واختبار قبول كامل في CI. **لم تُعتمد بوابة Docker بعد:** الجهاز المحلي بلا Docker، ولم تُشغّل وظيفة CI أو يُنشر الدومين الفعلي ضمن هذه الدفعة. يلزم نجاح البناء والتشغيل والحفظ والنسخ والاستعادة في وظيفة `docker`، ثم اختبار DNS وHTTPS دون تجاوز الثقة، وSMTP الفعلي، ونقل البيانات القائمة وروابط QR والمراقبة على السيرفر. هذا الإعداد لا يغيّر حالة بوابات اعتماد التطبيق الأخرى أدناه.
