# خطة الاختبار

الاختبارات الحالية في `core/tests.py` تغطي عزل مطعمين وفروع متعددة في الصفحات والتعديل والتصدير، إنشاء الطلب العام وطلب الموظف متعدد الأصناف، السعر العشري ولقطته بعد تعديل المنيو، تعديل الطلب المقيد مع حفظ السعر الأصلي ونسخ المراجعة ومنع التكرار ورفض الطلب المدفوع أو المتقدم، واستيراد CSV مع المعاينة والحدود والاعتماد الذري ومنع تكرار الدفعة، رفض صنف أو خيار أجنبي، التوفر، انتقالات الحالات والإلغاء، تسجيل التحصيل اليدوي، متوسطات أزمنة التشغيل، استدعاءات الخدمة، حدود الباقة الأساسية والتفعيل بعد خفضها، تعطيل الموظف، استعادة كلمة المرور وتحديد معدلها ومعدل الدخول، تحديث شاشة المطبخ، وصلاحيات وإجراءات مشغل المنصة.

تغطي الاختبارات أيضًا دعوة الموظف بالبريد وقبولها مرة واحدة، وربط الدور والفرع، وقبول حساب موجود، وانتهاء الدعوة وإلغاءها، وحدود الباقة وفشل الإرسال. شغّل `python manage.py test core`. قبل الإطلاق، اختبر تسليم البريد وقبول الدعوة عبر SMTP فعلي، وأضف اختبارات تزامن على PostgreSQL، وCSRF والصلاحيات لكل POST، وحدود الباقات المتزامنة، وانقطاع الشبكة، والطباعة الفعلية للـQR، واختبارات عرض مرئية على مقاسات هاتف وتابلت وكمبيوتر. يلزم اختبار استعادة نسخة احتياطية في بيئة تجريبية.

أضيفت اختبارات تصحيح حالة الطلب خطوة واحدة مع السبب وسجل الحالة والتدقيق وعزل المطعم ورفض الأدوار الأخرى والطلبات المدفوعة أو المسلّمة، ومنع تعديل الأصناف بعد بدء التحضير حتى عند تصحيح الحالة. أضيفت اختبارات حدود استجابة الخدمة لكل نوع استدعاء، وحساب التأخير من طوابع الخادم، والتحقق من إعدادات الفرع وعزلها.

تغطي اختبارات تحصيل الاشتراك اليدوي صلاحية مشغل المنصة، ودقة المبلغ، ورفض الفترة أو الطريقة أو المرجع غير الصالح، ومنع تكرار المرجع، وسجل التدقيق، وعرض سجل المطعم لمالكه فقط، وعدم تمديد الاشتراك تلقائيًا. تبقى مطابقة التحصيل الفعلي مع كشوف الحساب وإجراءات الفوترة خارج الاختبارات المحلية.

أُجري فحص بصري يدوي أساسي في Chrome لمقاسات 390 و768 و1440 بكسل على لوحة التحكم ومنيو الضيف، مع فحص عدم التمرير الأفقي وظهور فلاتر المطبخ. لا يغطي هذا جميع الصفحات أو الأجهزة الفعلية، ولا يُغني عن الاختبار الميداني.
