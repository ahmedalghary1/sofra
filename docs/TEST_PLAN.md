# خطة الاختبار

الاختبارات الحالية في `core/tests.py` تغطي عزل مطعمين وفروع متعددة في الصفحات والتعديل والتصدير، إنشاء الطلب العام وطلب الموظف متعدد الأصناف، السعر العشري ولقطته بعد تعديل المنيو، تعديل الطلب المقيد مع حفظ السعر الأصلي ونسخ المراجعة ومنع التكرار ورفض الطلب المدفوع أو المتقدم، رفض صنف أو خيار أجنبي، التوفر، انتقالات الحالات والإلغاء، تسجيل التحصيل اليدوي، متوسطات أزمنة التشغيل، استدعاءات الخدمة، حدود الباقة الأساسية والتفعيل بعد خفضها، تعطيل الموظف، استعادة كلمة المرور وتحديد معدلها ومعدل الدخول، تحديث شاشة المطبخ، وصلاحيات وإجراءات مشغل المنصة.

شغّل `python manage.py test core`. قبل الإطلاق، أضف اختبارات تزامن على PostgreSQL، وCSRF والصلاحيات لكل POST، وحدود الباقات المتزامنة، وانقطاع الشبكة، والطباعة الفعلية للـQR، واختبارات عرض مرئية على مقاسات هاتف وتابلت وكمبيوتر. يلزم اختبار استعادة نسخة احتياطية في بيئة تجريبية.
