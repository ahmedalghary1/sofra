# خطة الاختبار

الاختبارات الحالية في `core/tests.py` تغطي عزل مطعمين في الصفحات والتصدير، إنشاء الطلب العام، السعر العشري ولقطته، منع التكرار، رفض صنف أو خيار أجنبي، التوفر، انتقالات الحالات، استدعاءات الخدمة، وعرض الصفحات الإدارية.

شغّل `python manage.py test core`. قبل الإطلاق، أضف اختبارات تزامن على PostgreSQL، وCSRF والصلاحيات لكل POST، وحدود الباقات المتزامنة، وانقطاع الشبكة، والطباعة الفعلية للـQR، واختبارات عرض مرئية على مقاسات هاتف وتابلت وكمبيوتر. يلزم اختبار استعادة نسخة احتياطية في بيئة تجريبية.
